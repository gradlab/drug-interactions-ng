# drug-interactions-ng
This repository contains data and code and for *"In vitro evaluation of the activity of pairwise combinations of zoliflodacin, gepotidacin, and ciprofloxacin against Neisseria gonorrhoeae"*

Authors: Bailey Bowcutt, Aditi Mukherjee, Samantha G. Palace, and Yonatan H. Grad

To run this code, please first ensure you change your home directory under setwd("path/to/your/folder") by changing the pathway within the quotations. 

The code should be ran in the following order within Rstudio: 
1. drug_interactions_gepo_cipro_publish.R
2. drug_interactions_zoli_cipro_publish.R
3. drug_interactions_zoli_gepo_publish.R
4. table_1_2.R (this is a combined file of the table 1 and 2 results)
5. supplementary_figure_4_mean_MIC.R
